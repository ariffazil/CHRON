## Findings and fixes

### F1 — HIGH — CLI exposed only 7 of 21 tools
`python3 -m chron call chron_temporal_briefing` returned `Unknown tool`; `chron tools` listed the legacy `chron_mcp.py` surface (7 tools). The live MCP server was always 21 tools — the CLI was reading a different registry.
**Fix:** `__main__.py` now routes `call` and `tools` through `chron.server`; legacy names kept as fallback/alias (`chron_calibration → chron_calibration_state`). Verified: briefing, attention debt, and tool listing all return canonical data.

### F2 — HIGH — Early-falsifier scan was ledger-blind (60 false DUE)
Scan reported **DUE 60** while `chron_predictions_due` reported **0**. Cause: the scanner ignored `verification_log.jsonl`, so 49 already-closed predictions plus terminal-status rows were labelled DUE every morning.
**Fix:** scanner now imports `resolved_ids()`, skips decisive/CLOSED-UNTESTABLE verdicts and terminal birth statuses. Result: **DUE 0**; new `UNBOUND_OVERDUE` bucket names the real zombie class. `binding_scan.json` regenerated.

### F3 — HIGH — 7 past-date predictions were invisible to every queue
`get_due()` iterates `get_active()`, which only accepts `status == ACTIVE`. Seven `UNBOUND` predictions were past `verify_at` with no closure record — never verified, never scored, never closed. Three were actually resolvable on existing evidence; four were not.
**Fix:** closed all 7 through the MCP write path:
- **CORRECT (3):** nasi-lemak run (GPS log), verdict-field falsification (event resolution), QRL/ThinkingBox ST002_001 (`errors.jsonl` documents the operational blockage).
- **UNVERIFIABLE/CLOSED (4):** attractor shadow watch, aforge-shadow seed, AT-010 contract, Perplexity grant — windows shut with no measurement captured.
Also: `chron_predictions_due` now returns `stale_unbound[]` + `stale_unbound_count`, so this class cannot hide again.

- `hermes-attractor-shadow-watch-7d`: log has **one** line (armed 2026-10-02), no per-day record through 2026-10-09. Closed **UNVERIFIABLE** — zero-leakage cannot be claimed because it was not measured. Not CONFIRMED.
